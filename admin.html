匯出 · 部署
更新網站內容只需三步驟，不需要寫程式
匯出 content.json，然後上傳到 Netlify
儲存變更後，按下方按鈕下載 content.json，再上傳至 Netlify 完成更新。
三步驟更新網站
1
在後台完成編輯，按「儲存所有變更」
右上角的橘色按鈕。儲存後內容會保存在這台電腦的瀏覽器中。
2
按「匯出 content.json」下載檔案
這個 JSON 檔案包含所有你編輯過的文字內容（不含本機上傳的照片；照片請使用外部網址）。
3
前往 Netlify，上傳整個 venue 資料夾
把下載的 content.json 放入 venue 資料夾，然後到 app.netlify.com → 你的 site → Deploys → 把整個資料夾拖進去。 約 30 秒後網站即更新。
首次部署設定（只需做一次）
A
前往 Netlify 建立新網站
登入 app.netlify.com → Add new site → Deploy manually → 將整個 venue 資料夾拖進去。
B
綁定 venue.lava.tw 子網域
Netlify → Domain management → Add domain → 輸入 venue.lava.tw。
然後到你的 DNS 服務商（通常是購買網域的地方）新增一筆 CNAME 記錄：
venue → Netlify 提供的 *.netlify.app 網址。
C
開啟 HTTPS（免費）
DNS 生效後（通常幾分鐘至 24 小時），Netlify 的 SSL certificate 會自動啟用。
匯入 · 備份
還原設定，或清除所有變更恢復預設
從 content.json 匯入

貼入先前匯出的 content.json 內容，點擊「套用」後請再儲存一次以生效。

危險操作

清除後台所有儲存的設定與照片，網站將回到程式預設值。此操作無法復原。
